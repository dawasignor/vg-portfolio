# Ambient sound slots

Each stop in `content/journeys/masters.json` names a sound file in `public/audio/` (`"sound"`).
Drop a file in with that name, or change the name in the JSON. Loops play from
that stop until the next one, crossfading, and only after the reader turns sound on.
A missing file means silence.

| File | Stop |
|---|---|
| `base-camp.mp3` | Joining the ABCD-Centre |
| `river.mp3` | Contaminant Transport Modelling |
| `village-mill.mp3` | Sustainable River Basin Management |
| `windmill-wind.mp3` | Physicochemical Treatment of Wastewater |
| `gulls-and-sea.mp3` | Climate Adaptation and Coastal Engineering |
| `well.mp3` | Groundwater Engineering |
| `mountain-foot.mp3` | The first semester ends |

Keep loops short (20–60 s) and seamless, and use MP3 or OGG.

**GDPR:** recordings can hold people's voices and conversations, which are personal
data. Use recordings with no recognisable voices, or cut those parts out, before a
file goes in here.
